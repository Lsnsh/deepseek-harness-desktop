### What is this project? / 这是什么项目？

**DeepSeek Harness Developer Preview** is a community-maintained, all-in-one
**native desktop client** for
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness):

- 📦 **No Node.js install needed** — bundles its own Node.js LTS runtime
  (v24.19.0) and the latest `@deepseek-ai/dsh`
- 🚀 **Ready to run** — starts `dsh web` right on launch
- 🖥️ **Native experience** — Tauri 2 window, system tray, native menus,
  single instance
- 🔔 **Session notifications** — notified when a session turn completes;
  click to jump back to the window
- 🔄 **Auto-update** — delivered via GitHub Releases with signed manifests
- 🧩 **Plugin manager** — install / search / remove `dsh-plugin` topic plugins

**DeepSeek Harness Developer Preview** 是 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)
的社区维护型一体化 **原生桌面客户端**：

- 📦 **无需安装 Node.js** — 内置 Node.js LTS 运行时（v24.19.0）与最新版 `@deepseek-ai/dsh`
- 🚀 **开箱即用** — 启动即自动运行 `dsh web`
- 🖥️ **原生体验** — Tauri 2 窗口、系统托盘、原生菜单、单实例运行
- 🔔 **会话完成通知** — 会话回合完成时弹出通知，点击即可回到窗口
- 🔄 **自动更新** — 通过 GitHub Releases 分发，带签名更新清单
- 🧩 **插件管理器** — 安装 / 搜索 / 移除 `dsh-plugin` 主题插件

> ⚠️ A community-maintained **third-party** client, **not affiliated with
> DeepSeek**. Currently in **beta (Developer Preview)**, supporting **macOS
> (Apple Silicon) only**; Windows / Linux support is on the roadmap.

> ⚠️ 这是一个社区维护的**第三方**客户端，**与 DeepSeek 官方无关**。当前处于
> **beta（开发者预览版）**，仅支持 **macOS（Apple Silicon）**；Windows / Linux
> 支持已在路线图中。

### Why Discussions? / 为什么使用 Discussions？

During the developer preview, Issues and PRs are closed so we can focus on
maintenance. **Discussions is our only channel** — questions, ideas, feedback,
and bug reports all live here. We hope that you:

- Ask questions you're wondering about. / 提出你好奇的问题。
- Share ideas and feature suggestions. / 分享想法与功能建议。
- Report bugs with reproduction details. / 反馈问题，并附上复现信息。
- Engage with other community members. / 与其他社区成员互动交流。
- Welcome others and stay open-minded. This is a community we build
  together 💪. / 欢迎新朋友、保持开放心态——这是我们共同建设的社区 💪。

开发者预览阶段，仓库关闭了 Issues 和 PR，以便我们集中精力维护。**Discussions
是唯一的交流渠道**——提问、想法、反馈和问题报告都在这里进行。

### How to report a bug well / 如何更好地反馈问题

When reporting a bug, please include:

- App version (e.g. `v0.1.0-beta.8`) / 应用版本（如 `v0.1.0-beta.8`）
- macOS version and chip (Apple Silicon) / macOS 版本与芯片（Apple Silicon）
- Steps to reproduce / 复现步骤
- Expected vs. actual behavior / 预期结果与实际结果
- Logs if possible (`~/.dsh`, system log dir) / 如有可能，附上日志（`~/.dsh`、系统日志目录）

### Community guidelines / 社区守则

- **Search before posting** — your question may already be answered /
  发帖前先搜索，你的问题可能已有答案
- **One topic per discussion** — keep threads focused /
  一个讨论聚焦一个主题
- **Both languages welcome** — 中文和 English 都可以 /
  中英文发帖均受欢迎
- **Be respectful** — no spam, harassment, or promotional content /
  互相尊重，拒绝广告、骚扰与推广内容
